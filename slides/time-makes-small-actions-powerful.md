# Future Value

### What recurring contributions become over time

::left::

<div class="finance-card finance-card-compact text-left mt-1">
<div class="text-sm"><strong>Future value (FV)</strong> — the total you end up with after <strong>n</strong> years, earning return <strong>r</strong>, when you add <strong>PMT</strong> each period.</div>
</div>
<div class="finance-formula-block">
<div class="finance-formula-eq">
<span class="finance-formula-var">FV</span>
<span class="finance-formula-op">=</span>
<span class="finance-formula-var">PMT</span>
<span class="finance-formula-op">×</span>
<span class="finance-formula-frac">
<span class="finance-formula-num">(1 + r)<sup>n</sup> − 1</span>
<span class="finance-formula-den">r</span>
</span>
</div>
<dl class="finance-formula-legend">
<dt>PMT</dt><dd>payment each period (your capital injection)</dd>
<dt>r</dt><dd>return per year (as a decimal, e.g. 0.07 = 7%)</dd>
<dt>n</dt><dd>number of years</dd>
</dl>
</div>
<a href="https://www.td.com/ca/en/personal-banking/personal-investing/compound-interest-calculator" target="_blank" rel="noopener" class="finance-link text-sm mt-3 inline-block">TD — Compound Interest Calculator →</a>

# Currency risk — answering objection 3

### "I only trust cash / one currency" — but FX moves still cost you

<div class="finance-slide mt-4">
<div class="grid grid-cols-2 gap-6">
<div class="finance-card finance-card-compact text-left">
<div class="font-bold text-lg mb-2">Example: USD/CAD</div>

<span class="text-xl">→</span>
<span class="finance-num text-3xl">1.42</span>
</div>
<div class="finance-sub mt-2 text-sm">Move: <strong>+0.09</strong> (illustrative — same idea as your outline)</div>

<a href="https://www.tradingview.com/symbols/USDCAD/?timeframe=12M" target="_blank" rel="noopener" class="finance-link-on-dark text-xs mt-2 inline-block">TradingView — USD/CAD 12M chart →</a>

<div class="text-sm">C$8,000 × 0.09 =</div>
<div class="finance-num text-3xl mt-1">C$720</div>
<div class="finance-sub text-xs mt-1">Extra cost from FX move alone</div>
<div class="finance-sub text-xs mt-2">If USD/CAD rises, paying in U.S. dollars costs more in loonies — even if you "only hold cash."</div>
